# 🐟 ForGavin · 摸鱼（Relaxed and Happy）

> 一个「所有功能都可自由开关」的 Factorio 辅助模组，节省垃圾时间，提升游戏体验。兼容多个大型模组（Space Age / Krastorio 2 / Space Exploration / Nullius）。
>
> 仅限 Gavin1978 个人使用 —— **当前版本：2.1.11**

---

## ✨ 主要功能

所有功能均可在设置中独立开关：

### 玩家与开局
- **个性设置**：修改玩家属性（背包容量、移动速度、施工距离、远程距离等）
- **开局物品**：简易开局 / 富有开局（含 K2 开局机甲、蜘蛛燃料、SE 专属装备）
- **建筑师开局**：可选装备方案，含能量装甲 MK4、核能建筑机器人

### 装备与强化
- **装备强化（Enabled-and-Enhance / Legendary）**：发电模块、机器人模块、外骨骼、电池、护盾（×100 强度/输入/缓存）、激光防御（10 倍射速 + 射程翻倍）按比例放大
- **电池充放电倍率**：遍历所有类型蓄电器（含模组添加的）
- **轨道太阳能加成**：适配 SE / 喷气背包

### 建筑与物流
- **电线杆范围**：可选统一 64×64（含模组添加的电线杆），广域电线杆自带白光发光
- **机器人平台**：范围（默认 / 64 / 128 格）+ 强化模式 + 充电口数量 + 充电速率
- **建筑增强**：合并制造类别、铸造厂可冶炼/浇筑配方、电磁工厂可离心、低温工厂可炼油
- **管道**：流体最大链接长度调整（全种类）、随地泵、矿机筛选
- **自由传送**：快捷键 `Ctrl+Shift+T` 或快捷栏按钮（动态充能光环 + 蓝色粒子）
- **自由穿梭**：缩小碰撞箱，可穿过建筑缝隙

### 其他
- **物品变质时间倍率**（0.1 ~ 100）
- **允许所有配方使用品质模块**（启用 quality 时生效）
- **手搓革命 / 即时手搓**、机器人速度倍率与能耗配置
- **火箭发射统计**：`/rocket-stats`，可独立开关并自定义报告间隔
- **永续箱**（作弊选项）等

## 📦 安装

1. 从本仓库 **Releases** 下载 `ForGavin_<版本>.zip`
2. 解压后放入游戏 `mods` 目录（或直接用管理器的模组下载功能）
3. 在游戏启动时勾选启用

> 也可以从 **Mod Portal** 下载（`https://mods.factorio.com/mod/ForGavin`）
